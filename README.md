# Poodll ReadAloud for Moodle

**A guided reading-fluency and reading-comprehension activity for Moodle, graded automatically by speech recognition and AI.**

The teacher sets a reading passage. The student works through a structured journey — listen to
the passage, practice it line by line, read the whole thing aloud, then (optionally) take a quiz
about it. ReadAloud scores the reading automatically for words-per-minute and accuracy, and can
follow it with a full comprehension/vocabulary/writing quiz, all inside the one activity.

## Requirements

| | |
|---|---|
| Moodle | 5.0 or later (`$plugin->requires = 2025041400`) |
| PHP | 8.1+ |
| Database | MySQL / MariaDB / PostgreSQL |
| Cloud Poodll account | **Required.** An API user and secret from https://poodll.com |

ReadAloud relies on the Cloud Poodll service for audio recording, text to speech, speech
recognition and AI grading. Without API credentials the activity will not function.
See [Cloud Poodll API secret](https://support.poodll.com/support/solutions/articles/19000083076-cloud-poodll-api-secret)
for how to obtain them.

## Installation

1. Copy the plugin folder to `mod/readaloud` in your Moodle code root (on Moodle 5.1 and above this is
   `public/mod/readaloud`).
2. Visit **Site administration → Notifications** and complete the upgrade.
3. Enter your Cloud Poodll API user and secret at
   **Site administration → Plugins → Activity modules → Poodll ReadAloud**.

## The student journey

A ReadAloud activity is built from a passage plus a set of steps, toggled per activity:

| Step | What happens |
|---|---|
| **Listen** | The student listens to the passage (audio you supply, or generated by text to speech) before attempting it. |
| **Practice** ("Listen and Repeat") | The passage is broken into lines with model audio for each; the student practices reading along line by line. Model audio is managed from the activity's **Model Audio** tab — record or generate it, and it's automatically split into sentence-level clips. |
| **Read** | The student reads the whole passage aloud, recording as they go. This is the graded attempt: words-per-minute and accuracy, scored automatically. |
| **Quiz** | An optional follow-up quiz about the passage — see [The quiz step](#the-quiz-step) below. |
| **Report** | Students and teachers see the results: WPM, accuracy, the marked-up transcript, and (if AI is enabled) written feedback. |

At least one step must be enabled. Reattempts, an early-exit option, and a target WPM (used to
scale the score to 100%) are all configurable per activity.

### Tuning the read-aloud grading

- **Alternatives** — specify acceptable mistranscriptions per word (e.g. `their|there|they're`)
  so near-homophones aren't marked wrong. See the
  [tuning guide](https://support.poodll.com/support/solutions/articles/19000096937-tuning-your-read-aloud-activity).
- **WPM adjust (AI)** — choose whether reading errors are fully subtracted from the WPM score,
  discounted by a fixed amount, or ignored.
- **Guided vs. open speech-to-text** — choose between Poodll's guided transcription (matched
  against the expected passage) or strict open transcription.
- **Evaluation display** — control what students see after an attempt (human-reviewed result,
  machine result, or both).

## The quiz step

When enabled, the Quiz step adds a set of questions about the passage after the reading itself —
the same kind of item-based quiz mechanism used in Poodll MiniLesson, built into ReadAloud
directly. 

## Grading

- Reading attempts are graded for words-per-minute and accuracy against the passage, using
  speech recognition, with the tuning options above.
- Grade calculation method (highest/latest/average of attempts, etc.) is configurable, as is
  whether human or machine (AI) grading determines the score shown to the student.
- **Master instance / Push** — designate one ReadAloud as a master and push its settings out to
  other ReadAloud activities of the same name across the site, so a shared configuration stays
  in sync.

## Reports and admin tabs

Teacher tabs on the activity: **View** (preview), **Grading**, **Reports**, **Setup** (if
enabled), **Questions** (quiz item authoring), **Model Audio**, **Administrator**, and **Push**.
Reports and Grading let a teacher review WPM/accuracy per attempt, listen to recordings, read
the marked-up transcript, and override AI grades by hand.

Over 60 speech recognition / TTS locales are supported, including multiple variants of English,
Spanish, French, German, Portuguese, Chinese, Japanese, Korean, Arabic, Hindi and many more.

## Mobile support

ReadAloud is supported in the Moodle mobile app via `db/mobile.php`.

## Privacy

ReadAloud stores personal data: attempts, WPM/accuracy scores, session data, recordings and
transcripts. Recordings are stored via Cloud Poodll (AWS S3), and the Moodle user id appears in
recording/transcript URLs. The plugin implements the Moodle Privacy API for export and deletion.
